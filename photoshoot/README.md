# JR Captures product photoshoot mockups

AI-styled sample product imagery based on the existing catalog, created with the built-in image generation tool on 30 October 2026. These are product visualizations, not photographs of manufactured customer orders.

The original supplier sheets and existing wooden gift photos remain in the repository for reference and rollback. Product names, prices, sizes, enquiry links and ordering logic are unchanged.

## Prompt set

1. Transform each existing supplier sheet into realistic professional product photography while preserving the sheet aspect ratio, product positions, silhouettes, photo openings and printed designs. Use warm neutral plaster walls or light wood tabletops for frames and engravings, soft natural window light, realistic material depth and contact shadows, and cream upholstery for plush gifts. Preserve the existing product assortment; do not add products or clock mechanisms.
2. Remove external supplier codes, prices, courier/dispatch labels, arrows, category captions and cell borders. Fill these areas with matching photo backgrounds while preserving all products, their positions, and text printed on the products.
3. Targeted corrections: remove an unintended clock mechanism from photo frame 1402; use a tabletop backdrop for table stand 1354.

## Asset format

Each SVG is a self-contained wrapper around an optimized WebP raster generated from its source sheet. There is no script or external resource dependency. Existing CSS sprite coordinates select products for the category cards, catalog cards and large product views. Additional crop margins give the products breathing room.
