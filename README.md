# JR Captures

Website for photography, videography, and personalized photo gifts in Madurai.

Published website: https://jr-captures.pages.dev/

## Recovery

Website files recovered from the publicly deployed Cloudflare Pages site. This is a copy of the published frontend, not an export of original development files or private backend code. External image and font services remain external dependencies.

## Preview

Run `python3 -m http.server 8000` in this folder and open http://localhost:8000/.

Adding files here does not automatically connect or move the existing Cloudflare Pages project.
